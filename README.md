# grit-frontend
React-Frontend APP for Grit — a tool to log developer friction, tag it, and surface recurring patterns with AI-generated summaries.

**Version:** 0.4.0

## STACK
- React -19
- Tanstack router and query
- React Hook Form
- Zod (Validation)

```bash
git clone https:/github.com/nathnaeltamirat/grit-frontend.git  
cd grit-frontend
npm i
npm run dev
```

## Scripts
```bash
npm run dev - To run the app on dev mode  
npm run lint - Eslint  
npm run lint:fix - To fx eslint problems  
npm run build - To build the app    
npm run start - To start the app  
```
